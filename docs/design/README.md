# Design Reference

> Historical planning document. For the current site architecture, design system, and maintenance rules, see `src/pages/site-guide.mdx`.

`homepage-reference.png` is the primary visual reference for the homepage.

Use it as a direction, not as a pixel-perfect specification.

Important characteristics:
- warm cream background
- generous whitespace
- editorial / Notion-like visual language
- text-led hero on the left
- character illustration on the right
- restrained black/grey palette
- muted blue-green as the only accent
- avoid generic SaaS styling

`public/images/character.svg` is the actual character asset.
Do not redraw or replace it during Phase 1.
